# 국세청 사업자 상태조회 연결

## 먼저 준비할 것

1. [공공데이터포털 국세청 API](https://www.data.go.kr/data/15081808/openapi.do)에 로그인합니다.
2. **국세청_사업자등록정보 진위확인 및 상태조회 서비스**에서 활용신청을 합니다. 사업자번호로 조회하는 `상태조회` 기능을 사용합니다.
3. 신청이 승인되면 발급된 일반 인증키를 확인합니다. Encoding/Decoding 키 모두 지원하지만 **Decoding 키** 입력을 권장합니다. 이 서비스는 무료로 안내되어 있습니다.
4. 아래 개인 설정 파일에 키를 입력하고 앱을 완전히 종료한 뒤 다시 실행합니다.

```properties
app.nts-service-key=발급받은인증키
```

- IntelliJ·start-local.cmd 등 소스 실행: 프로젝트 폴더의 `application-local.properties`
- 배포 EXE: 기본 데이터 폴더인 `%LOCALAPPDATA%\ReceiptToExcel\application-local.properties`
- EXE의 `--data-home`을 별도 지정했다면 그 데이터 폴더의 개인 설정 파일을 사용합니다.
- 처음 설정할 때는 예제 파일을 복사해 이름을 바꿀 수 있습니다. 이미 설정 파일이 있으면 기존 내용을 덮어쓰지 말고 위 한 줄만 추가하세요.
- 환경변수 `NTS_SERVICE_KEY`로 설정하는 방법도 지원합니다. 개인 설정 파일에 같은 속성을 적었다면 파일 값이 우선합니다.
- 키는 채팅·GitHub·릴리스 ZIP·공유 스크린샷에 넣지 마세요. 프로젝트의 개인 설정 파일은 `.gitignore`로 제외되어 있습니다.

키가 없어도 기존 OCR·장부·엑셀은 동작합니다. 화면의 **국세청 연결 방법** 버튼으로 설정 안내를 볼 수 있습니다. 실제 키가 발급되기 전에는 가짜 응답을 이용한 연결 테스트만 가능합니다.

## 조회 방법

1. 영수증을 올리고 판매점 사업자등록번호를 원본과 대조합니다.
2. 번호나 다른 입력값을 수정했다면 먼저 저장한 뒤 검토 창을 다시 엽니다.
3. **국세청 조회 · 새로 조회**를 누릅니다.
4. 과세유형·사업자 상태·조회 시각을 확인합니다. 제공되는 경우 과세유형 전환일·직전 유형·세금계산서 적용일·폐업일도 표시합니다.

자동 업로드나 재분석 때마다 외부 조회를 반복하지 않습니다. 사용자가 조회 버튼을 누를 때 저장된 사업자번호 한 건만 국세청 API로 보냅니다. 영수증 사진·금액·주소·사용자명은 보내지 않습니다. 인증키는 로컬 서버에서만 사용하고 브라우저 응답·장부·엑셀에 넣지 않습니다.

## 결과 의미

| 공식 코드 | 과세유형 |
|---|---|
| 01 | 부가가치세 일반과세자 |
| 02 | 부가가치세 간이과세자 |
| 03 | 부가가치세 과세특례자 |
| 04 | 부가가치세 면세사업자 |
| 05 | 수익사업을 영위하지 않는 비영리법인·고유번호 단체·국가기관 등 |
| 06 | 고유번호가 부여된 단체 |
| 07 | 부가가치세 간이과세자(세금계산서 발급사업자) |

공식 명세의 `tax_type` 명칭과 코드를 보존합니다. **간이과세는 면세·비과세와 같지 않습니다.** 02와 07을 임의로 합치지 않으며, 일반과세자라는 이유만으로 공제·환급 가능이라고 표시하지 않습니다. 기존 부가세 기장 방식이나 세액을 자동 변경하지도 않습니다.

조회는 영수증에 적힌 사업자번호 기준입니다. 같은 번호를 쓰는 여러 매장은 이 조회만으로 점포별 구분을 할 수 없습니다. 상호·주소를 찾아주는 API도 아니므로 기존 OCR 값을 덮어쓰지 않습니다.

결과는 **조회 시점**의 정보입니다. 현재 유형과 과거 거래 당시 유형은 다를 수 있으며 최근 전환일 정보만으로 모든 과거 이력을 복원할 수 없습니다. 실제 매입세액 공제는 거래 내용·증빙·고객 회사의 과세유형 등을 따로 검토해야 합니다.

## 실패·변경·기장 처리

- 미조회와 ‘국세청에서 조회되지 않음’은 구분합니다. 조회되지 않는 번호도 면세·불공제로 자동 판정하지 않습니다.
- 인증·통신·호출 한도 오류는 안내하고 과거 성공 결과와 그 조회 시점을 유지합니다. 새 조회가 성공한 것으로 바꾸지 않습니다.
- 사업자번호를 바꾸거나 재인식 결과의 번호가 달라지면 이전 조회 사본을 해제해 미조회로 돌립니다. 하이픈만 달라지면 같은 번호로 취급합니다.
- 조회 중 다른 창에서 영수증이 수정·기장되면 오래된 결과를 저장하지 않습니다.
- 기장된 영수증은 먼저 기장을 취소해야 조회를 갱신할 수 있습니다. 기장 당시 조회 결과는 전표에 복사하며 취소 이후 원본이 바뀌어도 보존합니다.

## 엑셀·Google Sheets

기존 Q열 사업자번호와 R열 거래 시간 뒤에 다음 항목을 출력합니다.

| 열 | 항목 |
|---|---|
| S | 거래처과세유형 |
| T | 사업자상태 |
| U | 사업자조회일시(UTC) |
| V · 마지막 | 거래처주소 |

미조회 건은 유형·상태를 `미조회`로 표시하고 조회 시각은 비웁니다. 분개장·취소 이력에도 기장 당시 결과를 출력하며 주소를 마지막에 둡니다. 기존 기장 전표는 소급 조회하지 않습니다.
