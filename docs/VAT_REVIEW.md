# 부가세 매입세액 공제 검토 제안

## 화면과 엑셀

영수증 검토 창에 저장된 자료 기준의 제안과 사유를 표시합니다. 내용을 수정한 뒤 저장하면 다시 계산합니다. 자동 제안은 사람이 확정한 공제 여부나 환급 예정액이 아닙니다.

지출장부·Google Sheets의 앞부분을 아래 순서로 배치합니다.

| 열 | 항목 |
|---|---|
| A | 관리ID |
| B | 지출일자 |
| C | 거래처 |
| D | 부가세 공제 검토 |
| E | 공제 검토 사유 |
| F 이후 | 계정과목·적요·금액 등 |
| X · 마지막 | 거래처주소 |

| 표시 | 의미 |
|---|---|
| 공제 후보 · 초록 | 명시된 세액·증빙·거래처 유형 등으로 검토 가능한 후보. 매입자 과세사업·업무 목적·원본·신고 요건은 최종 확인 |
| 불공제 검토 · 빨강 | 접대비 또는 거래 당시 유형을 확인할 수 있는 세금계산서 미발급 간이·면세 거래 등의 단서 |
| 세액 없음 · 회색 | 부가세에 0원이 입력되어 있음. 면세·영세 등 구체적인 유형은 별도 확인 |
| 확인 필요 · 노랑 | 정보 부족, 충돌, 거래별 예외 또는 추가 자료가 필요함 |
| 집계 제외 | 중복 제외된 내역. 기존처럼 확정 장부 내보내기 대상에서 제외 |

**불공제라고 해서 지출 원금까지 집계에서 빼지 않습니다.** 총금액·세액·계정별 합계·기장 방식은 자동 변경하지 않습니다. 부가세 불공제와 소득세·법인세상 비용 인정은 별개입니다.

## 주요 규칙

- 접대비(기업업무추진비)는 불공제 검토로 표시합니다. 다른 계정과목인데 적요에 접대·거래처 식사 등의 단서가 있으면 계정과목 확인을 요청합니다.
- 간이과세는 면세·비과세와 같지 않습니다. 국세청 코드 02와 07(세금계산서 발급사업자)을 구분합니다. 07도 증빙·세액·업무 관련성 등 나머지 조건 확인이 필요합니다.
- 일반과세자라는 이유만으로 공제 후보가 되지 않습니다. 양수의 명시 세액, 공급가액과 총액 일치, 증빙 종류, 거래 당시 유형 등을 함께 봅니다.
- 부가세 미확인(null)과 명시된 0원을 구분합니다. 총액을 나누어 세액을 만들지 않습니다.
- 개인카드 사용만으로 개인 지출·불공제로 분류하지 않습니다. 개인·가사 지출 단서는 업무 관련성 확인 대상으로 표시합니다.
- 주유·차량 정비·승용차·임차·리스는 차종·영업용 여부·업종별 예외 확인이 필요합니다.
- 교통수단·목욕·이발·미용·입장권·일부 의료 관련 항목은 카드전표 공제 대상 공급자·용역 제한을 확인하도록 표시합니다. 이름만으로 업종을 확정하지 않습니다.
- 토지 취득·조성, 면세사업 관련·공통매입, 국외 거래·수입·등록 전 매입 등의 단서는 개별 검토로 보냅니다.
- 도서인쇄비는 도서·문구·인쇄의 과세·면세 구분과 혼합 구매를 확인하도록 표시합니다. 서점 이름만으로 전체 금액을 면세 처리하지 않습니다.
- 기타경비·미분류·사용 목적 누락은 공제 후보로 기본 분류하지 않습니다.
- 단순 현금·이체 내역은 적격 증빙을 확인하도록 표시합니다. 공제 후보에 사용하는 증빙 단서는 카드 결제 또는 명시적인 지출증빙용 현금영수증·세금계산서입니다. 원본 진위와 필수 기재사항까지 자동 검증한 것은 아닙니다.

## 과거 거래와 조회 결과

과거 영수증이라는 이유만으로 확인 필요로 차단하지 않습니다. **전환일 미제공은 과세유형이 바뀌었다는 뜻도, 바뀐 적이 없다는 뜻도 아닙니다.** 실제 전환일과 충돌하지 않고 나머지 세액·증빙 조건을 충족하면 현재 조회 기준의 조건부 공제 후보로 표시하며 사유에 거래 당시 과세유형 확인이 필요하다는 점을 남깁니다. 오래된 날짜라는 이유로 임의의 기간 제한을 두지 않습니다.

거래일이 제공된 최근 전환일보다 이전이거나, 07 유형의 세금계산서 적용일보다 앞서면 계속 확인 필요로 남깁니다. 거래일이 조회일보다 미래인 경우도 확인 필요입니다. 현재 휴업·폐업 상태만으로 과거 거래를 일괄 불공제하지 않습니다. 세액 누락·차량비·접대성 지출 등 다른 규칙도 계속 적용합니다.

과거 거래의 02·04 유형 불공제 검토도 현재 조회 기준임을 사유에 명시합니다. 현재 유형을 실제 거래 당시의 확정 유형으로 저장하거나, 세무사 확인을 완료한 것으로 취급하지 않습니다.

조회가 없거나 조회 번호가 다르거나 국세청에서 확인되지 않으면 확인 필요입니다. 이 제안 계산 때문에 국세청을 다시 호출하지는 않습니다.

## 한계와 최종 검토

영수증과 상태조회만으로 **매입자 회사의 과세·면세·겸영 구분, 실제 업무 목적, 차종과 직접 영업용 예외, 증빙 진위·필수 기재사항, 등록 전 매입 시점, 신고 반영과 안분 계산** 등을 모두 알 수는 없습니다. 공제 후보는 이러한 조건을 세무사가 확인할 자료입니다. 모든 불공제 사유를 빠짐없이 자동 판정한다고 보장하지 않습니다.

XLSX의 `부가세검토안내` 시트에도 기준·예외·출처를 넣습니다. 엑셀에서 직접 입력값을 바꿔도 제안 셀은 자동 재계산되지 않으므로 앱에서 수정·재출력하거나 세무사가 최종 수정해야 합니다. 빈 엑셀 양식에 직접 작성한 내역도 앱의 자동 검토가 적용되는 것은 아닙니다.

## 기장 사본

기장 당시 제안·사유·규칙 버전을 전표에 저장합니다. 취소 후 원본을 수정해도 과거 전표의 제안은 유지합니다. 기능 추가 전 전표는 사본이 없으므로 ‘확인 필요’로 표시하며 현재 규칙으로 소급 확정하지 않습니다. 분개장과 취소 이력에도 검토 열을 앞부분에 출력합니다.
