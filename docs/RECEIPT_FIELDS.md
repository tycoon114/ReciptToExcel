# 사업자번호·거래 시간·거래처 주소

## 인식과 검토

- 사업자등록번호: 판매점의 사업자 표기와 `3-2-5` 자리 번호를 확인합니다. 구분자 없는 열 자리는 사업자 표기가 있는 행에서만 읽습니다. 검증번호 계산으로 숫자 오류를 점검하고 `000-00-00000` 형식의 문자열로 저장합니다. 숫자를 추측해서 보정하지 않습니다.
- 공급받는자·고객·결제대행사의 번호는 자동 선택하지 않습니다. 여러 번호가 충돌하거나 OCR 방식마다 결과가 다르면 빈칸과 확인 안내를 남깁니다. 검토 폼에서 판매점 번호를 수정할 수 있습니다.
- 검증번호가 맞아도 실제 등록된 사업자임을 보장하지 않습니다. 국세청 조회는 별도 선택 기능으로 연결하며 공제·환급을 자동 판단하지 않습니다. [연결 안내](NTS_API.md)를 확인하세요.
- 거래 시간: `13:04`, `13:04:09`, 오전·오후 표기와 명시적인 거래시간 뒤 여섯 자리 시각을 처리합니다. 거래·승인·결제 일시를 우선하며 영업시간·출력시간은 제외합니다. 초가 없으면 임의로 `00`을 추가하지 않습니다. 후보가 충돌하면 비웁니다.
- 주소: 판매점의 주소·소재지 표기 또는 지역명으로 시작하는 도로명·지번 주소를 읽습니다. 일부 줄바꿈을 연결하되 전화·사업자번호·금액 행은 제외합니다. 배송지·고객 주소는 선택하지 않습니다. 원문이 흐리거나 후보가 여러 개면 직접 확인해 주세요.
- 세 항목 모두 선택 사항입니다. 없는 영수증도 기존 필수 항목을 확인하면 확정·기장할 수 있습니다.

## 저장과 출력

검토 창에서 원본과 대조한 뒤 저장합니다. 목록에는 거래 시각과 사업자번호를 표시하며 사업자번호는 하이픈 유무와 관계없이 검색할 수 있습니다. 주소는 검토 폼 마지막 입력 항목입니다.

지출장부 XLSX와 Google Sheets는 기존 A~P열을 유지하고 다음 열을 덧붙입니다.

| 열 | 내용 |
|---|---|
| Q | 사업자등록번호 · 문자열 |
| R | 거래 시간 · 표시된 정밀도의 문자열 |
| S | 거래처 과세유형 |
| T | 사업자 상태 |
| U | 국세청 조회 시각(UTC) |
| V · 마지막 | 거래처 주소 |

빈 엑셀 양식에서도 번호 열은 텍스트 서식을 적용합니다. 분개장과 기장취소이력 엑셀에도 세 항목을 덧붙이며 주소가 마지막입니다. 계정별 합계에는 주소를 덧붙이지 않습니다.

기장 당시 값을 전표에 복사하므로 취소 후 원본을 수정해도 과거 전표의 정보는 유지됩니다. 기존 기장 전표에는 새 필드를 소급 입력하지 않습니다.

## 기존 장부

DB에 선택 열만 추가하며 기존 내역·증빙을 삭제하거나 자동 재인식하지 않습니다. 과거 영수증은 검토 창의 **사진 다시 읽기** 또는 직접 입력으로 새 항목을 채울 수 있습니다. 기장 중인 내역은 기존과 같이 먼저 기장을 취소해야 수정할 수 있습니다.

새 소스를 사용해도 예전에 만든 EXE·ZIP은 바뀌지 않습니다. 소스를 실행하거나 새 배포본을 사용하세요.

## 검증 범위

개발 중에는 새 추출 규칙·임시 DB 저장·엑셀·기장 사본·기존 DB 보존에 관련된 테스트만 실행합니다. 전체 회귀 테스트는 기존 GitHub Actions CI에서 실행합니다. 합성 텍스트 검증과 실제 Windows OCR 인식률 검증은 구분합니다.
