# 연속 스캔 PDF 등록

0.3.0부터 JPG·PNG와 함께 PDF를 선택하거나 끌어 놓을 수 있습니다. Java 설치 없는 Windows 배포판에도 PDF 처리 라이브러리가 포함됩니다. 외부 변환 사이트나 PDF 프로그램을 설치할 필요가 없습니다.

## 이번 버전의 처리 기준

- **한 페이지에 영수증 한 장**을 기준으로, PDF 3쪽이면 영수증 3건을 검토 대기로 등록합니다.
- 사진만 들어 있는 휴대폰 스캔 PDF와 일반 PDF 모두 페이지를 이미지로 바꿔 기존 OCR 또는 사용자가 설정한 분석기로 보냅니다.
- PDF 텍스트층을 거래 값으로 바로 믿지 않고 보이는 페이지를 읽습니다. 자동 확정·자동 기장은 하지 않습니다.
- **PDF당 25MB·최대 20쪽**, JPG·PNG는 기존처럼 10MB까지 지원합니다.
- 한 페이지 안의 여러 영수증 자동 분리, 여러 페이지를 한 영수증으로 합치기, 암호화된 PDF는 이번 범위에 포함하지 않습니다.
- JPEG2000 압축 PDF는 별도 코덱 없이 처리하지 않습니다. 지원하지 않는 경우 일반 PDF·JPG로 다시 저장하라는 안내를 표시합니다. 일반적인 JPEG·PNG·흑백 JBIG2 스캔을 지원합니다.

## 사용하는 순서

1. 새 버전으로 프로그램을 재시작하고 브라우저를 새로고침합니다.
2. **사진·PDF 선택**에서 PDF를 선택합니다. 사진과 PDF를 함께 선택할 수도 있습니다.
3. 화면에 **PDF 2/5쪽 인식 중**처럼 현재 페이지가 표시됩니다. 페이지 수와 PC 성능에 따라 시간이 걸립니다.
4. 처리 후 신규·중복 제외 건수와 실패 페이지를 확인합니다. 여러 페이지 PDF는 지출 내역 목록에서 각 행을 열어 검토합니다.
5. 목록의 **PDF · 2/5쪽** 표시와 검토 창의 **원본 PDF 내려받기**로 출처를 확인합니다.
6. 원본과 비교해 내용을 수정·확정하고 필요하면 기장합니다.

## 중복·실패·삭제

같은 PDF 파일의 같은 페이지는 다시 등록하지 않습니다. PDF를 다시 올려도 직접 수정하거나 확정·기장한 기존 값을 덮어쓰지 않습니다. 재인식하려면 영수증의 사진 다시 읽기를 사용합니다. 기장 완료 건은 먼저 기장을 취소해야 재인식할 수 있습니다.

일부 페이지에서 처리 오류가 발생해도 나머지 페이지는 계속 처리합니다. 성공한 내역은 유지됩니다. 같은 PDF를 다시 선택하면 이미 등록된 페이지는 중복으로 제외하고 실패·삭제된 페이지를 새로 시도합니다. 브라우저를 닫아 중단한 경우에도 같은 방식으로 이어서 등록할 수 있습니다.
중복 기준은 **PDF 원본 파일 내용 + 페이지 번호**입니다. 같은 영수증이라도 다시 스캔하거나 PDF를 재저장해 파일 내용이 달라지면 새 내역이 될 수 있습니다. JPG와 PDF 사이의 의미상 중복까지 판별하지는 않습니다.

PDF 원본은 data/pdf에, 페이지 미리보기는 data/images에 저장합니다. 같은 원본을 여러 행이 공유하며 마지막 연결 영수증을 삭제할 때 원본도 정리합니다. 기장 이력이 있으면 영수증 삭제가 차단되므로 원본도 유지됩니다. 마지막 영수증을 삭제하면 공유 PDF 전체가 삭제되므로, 등록하지 못한 페이지가 있다면 원래 스캔 파일을 보관하세요.
페이지 사진을 회전·재인식해도 원본 PDF 자체는 바뀌지 않습니다. 백업은 프로그램 종료 후 data 폴더 전체를 복사하면 됩니다. 배포판의 기본 저장 위치는 사용자 계정의 %LOCALAPPDATA%/ReceiptToExcel/data입니다.

## 개발 구조

PDF 원본 등록과 페이지 인식을 나누어 진행 상황·개별 오류를 표시합니다. PdfDocuments는 원본 저장·파일 검사·페이지 렌더링을 담당하고 ReceiptService는 기존 분석·중복·장부 저장 흐름으로 연결합니다. 향후 한 페이지의 여러 영수증을 나눌 때는 이 페이지 이미지 단계에 영역 분리 기능을 추가할 수 있습니다.
기존 DB를 재생성하지 않고 PDF 출처 열과 원본 테이블만 추가합니다. 과거 JPG·PNG·직접 입력 내역은 그대로 사용할 수 있습니다.
