# 파일 형식이 다른 영수증의 중복 검토

사진·PDF를 새로 등록할 때 기존 영수증과 비교합니다. AI나 외부 API를 사용하지 않으며 실제 증빙 파일도 수정하지 않습니다.

## 표시와 사용 방법

- 같은 원본 파일 또는 같은 PDF의 같은 페이지는 기존처럼 자동 중복 제외합니다. 기존 내역이 확정 상태이면 알림에도 표시합니다.
- 다른 파일이지만 거래 정보가 겹치는 새 내역은 빨간색 **중복 의심**으로 보관합니다. 기존 확정 내역의 내용과 상태는 변경하지 않습니다.
- 기존 확정 내역과 겹치는 경우에는 업로드 후 알림창으로 알립니다. 여러 사진·페이지는 처리 결과를 모아 한 번 안내합니다.
- 검토 상태 필터의 **중복 의심**을 선택하거나 목록 위 안내에서 **중복 의심만 보기**를 누릅니다.
- 해당 행을 열면 이번 증빙과 기존 증빙, 거래일·상호·금액·승인번호 및 의심 근거가 나란히 나옵니다. 사진을 누르면 원본을 확대해 볼 수 있습니다.
- 다른 거래라면 해당 비교 대상에서 **별개 거래로 확인**을 누릅니다. 후보가 여러 개이면 각각 판단해야 합니다. 모든 후보를 확인한 뒤 일반 검토·확정을 진행합니다.
- 같은 거래라면 **이번 등록을 중복으로 제외**합니다. 기존 내역은 그대로 두며 새 증빙도 보존합니다. 제외 건은 장부 합계·엑셀·Google Sheets·기장 대상에 포함하지 않습니다.
- 잘못 제외했다면 **중복 제외** 필터로 내역을 열고 **중복 제외 취소 · 다시 검토**를 누릅니다. 자동 확정하지 않고 중복 후보부터 다시 확인합니다.

의심이 해결되기 전에는 확정·기장이 차단됩니다. 일반 검토 대기 건수와 중복 의심을 나누어 표시합니다. 제외된 내역도 전체 목록에서 확인할 수 있습니다.

## 판단 근거

- 거래일과 양수 총금액이 같고, 거래처 또는 선택적 승인번호가 일치하면 중복 후보입니다.
- 거래처는 공백·구두점·일반 법인 표기를 정리해 비교하며, 원문에서 유일한 사업자번호가 확인되면 함께 사용합니다. 서로 다른 사업자번호가 확인되면 합치지 않습니다.
- 승인번호 단독이나 가격·거래처 두 항목만으로 자동 차단하지 않습니다. 번호가 없어도 날짜·금액·거래처로 비교할 수 있습니다. 같은 금액의 정상 반복 구매나 다른 승인번호가 있는 경우도 사용자가 구분할 수 있습니다.
- JPG·PNG·PDF 페이지 이미지는 종이 영역의 밝기·획 배치를 작은 지문으로 만들어 비교합니다. 회전과 약한 압축 차이를 고려하고, 백지·균일한 이미지는 제외합니다. 거래일·금액이 모순되지 않으면서 일부 거래 근거가 같은 경우의 보조 수단입니다.
- 매출취소·승인취소 등 명시적인 취소 거래는 일반 매출과 구분합니다. 일반적인 교환·환불 안내 문구는 취소 거래로 취급하지 않습니다.

형식·화질·촬영 각도나 OCR 오류가 크면 후보를 놓칠 수 있습니다. 반대로 같은 양식의 정상 반복 구매가 후보에 나타날 수 있습니다. 이미지 유사도만으로 자동 삭제하거나 자동 제외하지 않습니다.

## 변경·보존

별개 거래 판단은 비교한 두 내역의 거래 정보와 이미지 지문에 연결해 보존합니다. 적요·비고만 바뀌면 유지하지만 날짜·금액·상호·승인번호 등 비교 근거가 바뀌면 다시 확인합니다. 비교 중 다른 창에서 내역이 바뀌면 오래된 판단 요청은 거절합니다.

기존 DB는 삭제하거나 다시 만들지 않고 중복 검토 상태·이미지 지문·비교 판단 테이블을 추가합니다. 이미 확정한 과거 내역을 이번 업데이트만으로 일괄 중복 처리하지는 않습니다. 이전 사진의 지문은 이후 비교할 때 필요한 경우에만 계산합니다.

직접 입력한 사진 없는 내역은 파일 중복 검토 대상에서 제외합니다. 중복 제외는 복구 가능한 보관 상태이며, 일반 삭제와 다릅니다. 기장 이력이 있는 증빙의 삭제 제한은 계속 적용됩니다.
