# 승인번호 (선택 항목)

승인번호는 카드 거래 등에서 발급되는 거래 확인용 번호입니다. 카드번호·사업자번호·전표번호와는 별도 값입니다.
없는 영수증도 있으므로 저장·확정·기장의 필수 조건으로 삼지 않습니다.

- 무료 기본 모드는 `승인번호`, `승 인 번 호`, `승인No.`, `승인:`, `AUTH CODE`, `APPROVAL NO` 같은 명시적 표기와 같은 줄 또는 바로 다음 줄의 값을 확인합니다.
- 숫자·영문 조합과 앞자리 0을 문자열로 보존합니다. 예: `00001234`, `00AB1234`.
- `[승인번호]`, `승인번호」`, `승인번호•`처럼 괄호·구분자가 있는 표기도 처리합니다.
- 표기는 읽혔지만 번호가 불확실하면 단어 좌표로 해당 부분만 잘라 두 크기로 다시 읽습니다. 두 결과가 같을 때만 보완하며 저장한 증빙 파일은 바꾸지 않습니다.
- `인 번 호`처럼 표기의 일부가 빠진 경우는 전체 이미지의 추가 인식 계기로만 사용합니다. 불완전한 표기 뒤의 숫자를 곧바로 승인번호로 채택하지 않습니다.
- 마스킹되었거나 번호가 여러 개이거나 OCR 전처리 결과마다 번호가 다르면 빈칸으로 두고 검토 안내를 표시합니다. 카드번호·거래번호를 승인번호 대신 채우거나 글자를 임의 교정하지 않습니다.
- 선택적 Ollama 모드도 승인번호를 문자열로 반환하도록 요청합니다. 숫자형 응답은 앞자리 0이 사라졌을 수 있으므로 채택하지 않습니다.

## 사용 방법

1. 업데이트 후 IntelliJ 또는 배포 프로그램을 재시작하고 브라우저를 새로고침합니다.
2. 새 영수증을 올리거나 기존 내역에서 **사진 다시 읽기**를 누릅니다. 기존 결과는 업데이트만으로 자동 재분석되지 않습니다.
3. 검토 창의 **승인번호 (선택)** 를 원본과 비교합니다. 직접 수정하거나 빈칸으로 지울 수 있습니다.
4. 저장·확정합니다. 목록의 결제수단 아래에서 보이며 검색창에 번호를 입력해 찾을 수 있습니다.

지출장부 XLSX와 구글 스프레드시트는 기존 열 순서를 유지하면서 P열에 승인번호를 출력합니다. 이어 Q열은 사업자번호, R열은 거래 시간, S열은 거래처 과세유형, T열은 사업자 상태, U열은 조회 시각이며 마지막 V열은 거래처 주소입니다. XLSX에서는 숫자가 아닌 문자열 셀이며 Google Sheets는 RAW 문자열로 전송합니다.
기장하면 승인번호 사본을 전표에도 저장합니다. 분개장·취소 이력 엑셀에 출력되며, 취소 후 원본을 수정하더라도 과거 전표의 번호는 바뀌지 않습니다.
기장 완료 내역은 먼저 기장을 취소해야 수정·재인식할 수 있습니다. 과거 전표에 새 번호를 소급해서 채우지는 않습니다.

기존 DB에는 선택 열만 추가합니다. 기존 데이터와 사진은 유지되고 과거 승인번호는 빈칸으로 시작합니다.
이미 등록된 같은 사진을 다시 올리면 중복 방지로 기존 내역이 표시되므로 **사진 다시 읽기** 또는 직접 입력을 사용하세요.

서체·화질에 따라 인식 오류는 남을 수 있습니다. 이 기능은 자동 제안이므로 확정 전 원본과 대조합니다.
