# ReceiptToExcel 0.3.1 — PDF 등록 및 영수증 인식 개선

이 내용은 0.2.0 대비 변경 사항입니다.

## PDF 영수증 등록 추가

- JPG·PNG와 함께 휴대폰 연속 스캔 PDF를 등록할 수 있습니다.
- 한 페이지에 영수증 한 장을 기준으로, 페이지마다 별도 지출 내역을 생성합니다.
- PDF당 최대 25MB·20페이지를 지원합니다.
- 페이지별 처리 진행 상황과 신규·중복 제외·실패 결과를 안내합니다.
- 일부 페이지가 실패해도 나머지는 계속 처리하며, 같은 PDF를 다시 올려 실패한 페이지를 재시도할 수 있습니다.
- 같은 원본 PDF의 같은 페이지는 중복 등록을 방지하고 기존 수정 내용을 덮어쓰지 않습니다.
- 각 내역에서 PDF 페이지 번호를 확인하고 원본 PDF를 내려받을 수 있습니다.

## 기존 OCR 인식 개선

- 승인번호 표기의 괄호·구분자 때문에 값이 누락되는 경우를 보완했습니다.
- 불확실한 승인번호는 단어 좌표로 해당 부분만 잘라 두 크기로 다시 읽고, 두 결과가 같을 때만 보완합니다.
- 승인번호 표기의 일부가 빠지거나 비슷한 글자로 읽히면 추가 인식을 시도합니다. 번호가 충돌하면 비워 두고 원본 확인을 안내합니다.
- 상호·사업자번호·대표자명이 같은 줄에 있는 영수증의 거래처 추출을 개선했습니다.
- 영문 브랜드 옆 QR 잡음, 별도 지점명, 매장 전화번호를 구분하는 처리를 보완했습니다.
- 총액과 모순되는 공급가액·부가세는 자동 입력하지 않고 원본 확인을 요청합니다.
- 특정 가게나 승인번호를 고정한 방식이 아닌 공통 규칙이며 JPG·PNG에도 적용됩니다.

## 개발·검증

- GitHub Actions CI를 추가했습니다. 푸시·PR·수동 실행으로 Windows·Java 17 환경에서 빌드와 전체 자동 테스트를 검증합니다.
- 현재 자동 테스트 120건을 검증하며 테스트 건수·실패 요약과 상세 보고서를 제공합니다.
- CI는 규칙과 업무 흐름을 검증합니다. 실제 영수증의 인식률과 Windows 배포판 실행은 별도 확인이 필요합니다.

## 실행 및 업데이트

1. `ReceiptToExcel-0.3.1-windows-x64.zip`을 받고 압축을 모두 풉니다.
2. 폴더 안의 `ReceiptToExcel.exe`를 실행합니다. 별도 Java 설치는 필요하지 않습니다.
3. 기존 버전 사용자는 프로그램을 정상 종료하고 사용자 데이터 폴더를 백업한 뒤 새 실행 폴더를 사용합니다. 같은 Windows 계정의 기존 장부는 계속 사용합니다.
4. 이미 저장된 인식값은 자동 변경되지 않습니다. 새 규칙을 적용하려면 해당 내역에서 **사진 다시 읽기**를 누른 뒤 원본과 비교하세요. 기장 완료 건은 먼저 기장을 취소해야 재인식할 수 있습니다.

## 사용 범위

- 기본 인식은 Windows 내장 OCR와 규칙을 사용합니다. 이번 버전에 별도 AI 모델이나 외부 AI API를 추가하지 않았습니다.
- 한국어 OCR 언어 기능이 없는 PC는 Windows에서 해당 기능을 추가해야 합니다.
- 한 PDF 페이지 안의 여러 영수증 자동 분리는 지원하지 않습니다.
- 같은 영수증을 JPG와 PDF로 각각 올리거나 다시 촬영한 경우의 내용 기반 중복 판별은 포함하지 않습니다.
- 기존 기장·승인번호 선택 입력·엑셀·Google Sheets 기능은 유지합니다. 승인번호는 필수값이 아닙니다.
- 고객은 Releases의 실행용 ZIP을 받으세요. Code → Download ZIP은 개발용 소스입니다. `.sha256`은 파일 무결성 확인용이며 실행에는 필요하지 않습니다.
