# 동봉 실행 환경 안내

이 프로그램에는 Eclipse Temurin / OpenJDK의 실행 환경이 포함됩니다. 별도 Java 설치 없이 ReceiptToExcel을 실행하기 위한 전용 구성입니다.
정확한 배포판·버전·빌드 정보는 `runtime-version.txt`, 모듈별 라이선스와 고지는 `runtime/legal`에 보존되어 있습니다.
OpenJDK는 GNU General Public License version 2 및 Classpath Exception 등의 조건에 따라 배포됩니다. 개별 파일의 고지를 함께 확인하세요.

- 배포판 및 소스 안내: https://adoptium.net/
- Temurin 17 바이너리 및 해당 릴리스의 소스 링크: https://github.com/adoptium/temurin17-binaries/releases
- Temurin 빌드 소스: https://github.com/adoptium/temurin-build
- OpenJDK 17 업데이트 소스: https://github.com/adoptium/jdk17u

애플리케이션 JAR 안의 외부 라이브러리 라이선스·NOTICE 자료도 원래 형태로 유지합니다.
