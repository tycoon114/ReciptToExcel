사용 및 연결 안내
1. 무료 기본 모드로 시작
사진 선택 → 업무 목적 입력 → 내용 검토 → 확정 순서로 사용합니다. 기본 모드는 Windows OCR 문자 인식과 키워드 규칙을 사용합니다. 인식이 어렵다면 직접 입력할 수 있습니다. AI 모드가 아닙니다.
PDF 연속 스캔
한 페이지에 영수증 한 장인 PDF를 선택하면 페이지별로 등록합니다. 최대 25MB·20쪽이며 암호화된 PDF는 지원하지 않습니다. 일부 페이지가 실패하면 성공한 페이지만 유지합니다. 같은 PDF를 다시 선택하면 실패·삭제된 페이지만 새로 등록하고 이미 등록된 페이지는 중복으로 제외합니다. 페이지 안의 여러 영수증을 자동으로 나누지는 않습니다. 검토 창에서 원본 PDF를 내려받을 수 있습니다.
중복 의심 확인
다른 파일 형식이라도 거래일·금액·거래처, 선택적 승인번호와 이미지가 비슷하면 빨간색 ‘중복 의심’으로 표시합니다. 이미 확정한 내역과 겹치면 업로드 후 알림이 나타납니다. 두 원본을 비교해 ‘별개 거래로 확인’하거나 ‘중복으로 제외’하세요. 의심이 남아 있으면 확정·기장할 수 없습니다. 중복 제외는 증빙을 지우지 않으며 나중에 취소할 수 있습니다. 이미지나 승인번호 하나만으로 자동 차단하지 않습니다.
사업자번호·거래 시간·주소
영수증에 적힌 판매점 사업자번호와 거래 시간을 읽습니다. 번호가 여러 개이거나 검증번호가 맞지 않으면 비워 두므로 원본과 대조해 수정하세요. 시간·주소도 선택 항목이며 주소는 엑셀 마지막 열에 출력합니다. 기존 내역은 사진 다시 읽기를 실행하거나 직접 입력하면 채워집니다. 일반·간이 조회나 세금 공제 판정은 아직 연결하지 않았습니다.
2. 무료 로컬 AI 사용 (선택)
Ollama와 이미지 분석 모델을 설치하면 영수증을 로컬 AI가 읽습니다. 설치와 모델 다운로드에는 인터넷과 저장 공간이 필요하며 속도는 PC 성능에 따라 달라집니다. 프로젝트 README의 설정을 참고하세요.
3. Google 스프레드시트로 열기
‘엑셀 내보내기’를 눌러 파일을 저장하고 Google 스프레드시트에서 파일 → 가져오기 → 업로드를 선택하세요. 계정 연결 없이 앱을 시험할 수 있습니다.
4. Google Sheets 직접 전송 (선택)
README에 따라 서비스 계정과 문서 ID를 설정하면 전송 버튼이 활성화됩니다. 전송할 때마다 확정된 전체 장부로 ‘영수증장부_APP’ 전용 탭을 갱신합니다. 이 탭의 직접 수정 내용은 다음 전송 때 반영되지 않으므로 앱에서 수정하세요. 다른 탭에는 쓰지 않습니다.
5. 경비 전표 기장
영수증 확정은 인식값 검토이며, 기장은 그 거래를 차변·대변 전표로 기록하는 별도 작업입니다. 확정한 영수증을 열어 기장일·상대계정·담당자·부가세 방식을 확인하고 전표를 기장하세요. 기장 후에는 취소 사유를 남겨야 원본 수정이 가능하며 취소 전표도 이력에 남습니다. 분개장과 계정별 발생 합계는 별도 엑셀로 내려받습니다. 회사 전체 회계장부나 세무 신고 자료의 완성을 의미하지 않습니다.
저장 위치와 사용 범위
프로젝트의 data 폴더에 DB와 사진이 저장됩니다. 백업할 때는 앱을 종료한 후 data 폴더 전체를 복사하세요. 구글 폼은 현재 연결되어 있지 않습니다. 이 버전은 내 PC에서 사용하는 1인용 프로그램입니다.
